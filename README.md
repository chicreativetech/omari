# Omari - The Omarchy Niri plugin

**Omari brings a Niri-style scrolling workflow to Omarchy.**

If you love the way the Niri Wayland compositor handles windows and workspaces, but still want to stay with the cool Omarchy gang, this plugin is for you.

Omari builds on Omarchy’s existing scrolling layout and enhances it to feel smoother, more natural, and much closer to the Niri experience.

## Features

- **3-finger swipe left/right** on the trackpad to smoothly scroll through windows in the current workspace.
- **3-finger swipe up/down** to switch between workspaces.
- Smoother and more fluid window scrolling and animations.
- **Niri-inspired Overview mode** — press `SUPER + ALT + O` or swipe up with **4 fingers** to zoom out and see your open windows and workspaces at a glance.
- **Niri-style ALT+TAB switching** makes it easy to preview and move between applications.
- Filter the ALT+TAB view to show:
  - All applications
  - Applications in the current workspace
  - Applications on the current display/output

Omari aims to bring the best parts of Niri’s navigation and window-management experience into Omarchy without changing the environment you already enjoy.
